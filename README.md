# FirebaseChatDemo

> Historical Android learning project; kept for reference rather than as a current starter template.

This repository follows Google's Firebase FriendlyChat codelab and demonstrates a Java Android chat client using Firebase Authentication, Realtime Database, and Storage.

## Status

- The project uses Android Support Library-era dependencies and an older Gradle/Android toolchain.
- It has not been revalidated with current Android Studio, Gradle, or Firebase SDKs.
- To experiment with it, create your own Firebase project and supply your own Android configuration. Do not reuse production credentials or database rules.
